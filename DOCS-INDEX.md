## ⚡ Quick Start Commands

### Create Repository (GitHub CLI)
```bash
gh repo create building-management-app --public --clone
cd building-management-app
```

### Copy Templates
```bash
cp BUILDING-MANAGEMENT-README-TEMPLATE.md README.md
cp docker-compose-template.yml docker-compose.yml
cp gitignore-template.txt .gitignore
mkdir -p .github/workflows
cp github-workflow-template.yml .github/workflows/ci.yml
```

### First Agent Prompt
```
Setup a full-stack building management application with FastAPI backend,
React frontend, PostgreSQL database, Docker, and GitHub Actions CI/CD
```
